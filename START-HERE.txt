RAG Documentation Chatbot - fixed version
=========================================

What this is:
Your RAG chatbot, updated so it runs on free cloud hosting. The
backend now uses Google's Gemini API instead of a local Ollama
install, uploads are private per visitor session, and the frontend
talks to the backend through one setting (VITE_API_URL).

Run it locally:
1. Backend:  cd backend && pip install -r app/requirements.txt
             set GOOGLE_API_KEY=your-gemini-key   (Windows PowerShell:
             $env:GOOGLE_API_KEY="your-gemini-key")
             python -m uvicorn app.main:app --reload
2. Frontend: cd frontend && npm install && npm run dev
3. Open http://localhost:5173 and ask a question about the sample PDF.

Deploy it (free):
1. Push this folder to your GitHub repo.
2. Render.com: New > Blueprint > pick the repo and branch. This reads
   render.yaml. Review the free plan and add GOOGLE_API_KEY only in
   the Render dashboard. Do not put it in source files.
3. Vercel: import the repo, set Root Directory to "frontend", and add
   VITE_API_URL = your Render URL as an environment variable.
4. Back in Render, add your Vercel URL to ALLOWED_ORIGINS.

Free tier notes: the Render service sleeps after 15 quiet minutes and
takes about a minute to wake; uploads live in memory/disk on Render's
free plan and vanish when the service restarts - visitors just
re-upload their PDF.
